🔀 Album Shuffle

初期設定 — Client ID の取得

初回のみ、Spotify側にこのアプリを登録して Client ID を取得します(3分ほど)。

  1. Spotify Developer Dashboard を開き、普段のSpotifyアカウントでログイン
  2. Create app を押す(App name / Description は自由。例: Album Shuffle)
  3. Redirect URIs に下のURLを1文字も変えずに(末尾の / も含めて)貼り付けて Add
  4. 「Which API/SDKs are you planning to use?」で Web API にチェックして Save
  5. 作成したアプリの Settings に表示される Client ID をコピーして、下に貼り付けて保存

※ アプリ作成者のアカウントが Spotify Premium である必要があります(2026年2月以降のSpotify APIの仕様)。
